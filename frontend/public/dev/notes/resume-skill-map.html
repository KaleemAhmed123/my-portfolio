01
Profile Signal

How the resume positions you

Full-stack infrastructure engineer with backend, cloud, integrations, and AI workflow ownership.

The strongest interview narrative is not "I know many tools." It is: I build production backend systems, integrate messy external systems, operate deployments, and use AI as an engineering multiplier while keeping human ownership.

Primary Identity

Backend/full-stack engineer with microservices, event-driven commerce, ETL, SaaS, and cloud deployments.

Secondary Edge

AI engineering: LLM integration, prompt engineering, RAG, agentic workflows, MCP servers, context management.

Proof Projects

JS ETL platform, Acordly AI form automation, Personalized Wallah marketplace, Gaza40+ student portal.

Interview Risk

The resume is broad. Interviewers may probe depth in system design, AWS, queues, payments, and AI reliability.

Priority

Revision priority for interviews

Use this order when time is limited.

P0 - Must Be Sharp

  • Node.js request lifecycle and async model
  • SQL transactions, indexes, locks
  • Redis caching and rate limiting
  • RabbitMQ retries, DLQs, idempotency
  • JWT, OAuth, RBAC, authz checks

P1 - Resume Claims

  • 12-service microservices design
  • Seller wallet and payout correctness
  • SAP/Salesforce/Ecommerce ETL upserts
  • Docker/Nginx/SSL/GitHub Actions deployment
  • Prometheus/Grafana/Sentry/Winston observability

P2 - Differentiators

  • LLM pipelines and RAG evaluation
  • MCP server development
  • Agentic workflow guardrails
  • OCR extraction confidence and validation
  • AI-assisted development philosophy

Stories

Project stories to prepare

Each story should include problem, constraints, design, tradeoffs, failure handling, and metrics.
JS ETL Platform: source-aware idempotent UPSERTs across SAP, Salesforce, Ecommerce; partial success; parallel file ingestion; ack files.
Acordly: OCR + LLM extraction, ACORD form mapping, multi-tenancy, OAuth/JWT, plans, payments, Docker deployment.
Personalized Wallah: 12 services, API gateway, RabbitMQ workflows, Redis, seller wallet, payout engine, observability.
Gaza40+: role-based student case management, document uploads, dashboards, offer verification, funding-gap tracking.
Adaptability: AI-assisted but human-owned development, reviewing AI output, challenging suggestions, protecting product taste and correctness.
